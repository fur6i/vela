Password manager

Cifratura locale AES-256-GCM e Windows DPAPI. Ogni compilazione richiede l’autenticazione Windows.

Importa da Arc

In Arc: Impostazioni → Avanzate → Esporta spazi e schede. Seleziona Arc Data Export.md per ricreare spazi, schede sospese e preferiti.

Per le password, esporta un CSV dal password manager di Arc e selezionalo insieme al file MD. Il CSV contiene password in chiaro: conservalo con cura ed eliminalo quando non serve più. Vela non lo copia né lo elimina.

Seleziona di nuovo il file MD per sistemare le cartelle già importate come spazi. L’anteprima indica quante schede verranno spostate.
